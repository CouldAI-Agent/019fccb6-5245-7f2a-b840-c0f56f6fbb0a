# MediAI Health Assistant

**MediAI Health Assistant** is an AI-powered healthcare application prototype that provides symptom checking, health insights, and medical knowledge search. 

**IMPORTANT SAFETY DISCLAIMER:**
*AI-generated health information is for educational purposes only and is not a medical diagnosis. Always consult a qualified healthcare professional for medical advice.*

## Features
- **Symptom Checker:** Enter symptoms and get insights powered by AI logic (mocked).
- **AI Health Chatbot:** Conversational assistant for health education.
- **Health Reports:** Generate downloadable summaries of your symptom checks.
- **Emergency Info & Knowledge Base:** First aid tips and medical resources.
- **Role-based Access:** Patient Dashboard & Admin Dashboard.

## Tech Stack
- Frontend: Flutter (Web, iOS, Android, macOS, Windows, Linux)
- UI: Material 3, custom responsive layouts, glassmorphism elements.

## Running the App
1. Ensure Flutter is installed.
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run -d chrome` to preview on Web.
